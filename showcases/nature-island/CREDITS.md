# Nature Island

A fictional island-travel showcase, created for Lucas Nguyen's portfolio on 27 October 2026. The places and day plans are illustrative; there are no real tours, reservations, customer testimonials or commercial results.

## Reference

The user supplied the local WordPress theme-install preview for **Variations**, by Tyler Moore. The visible preview at https://wp-themes.com/variations/ informed the pale blue sky, layered blue and coral scenery, striped lighthouse, generous serif heading and relaxed island setting.

The HTML, CSS, JavaScript, copy and SVG illustrations in this directory were authored for this showcase. No WordPress theme source or image assets were imported. This is a static portfolio interpretation, not an installation of Variations or a claim to have designed that theme.

## Assets

- `assets/island.svg`: original layered coastal panorama with a lighthouse, pines, sailboat and sun.
- `assets/cover.svg`: portfolio cover derived from the original panorama.
- `assets/cove.svg`, `assets/forest.svg`, `assets/lighthouse.svg`: original destination vignettes.
- `assets/postcard.svg`: sunset postcard variation of the panorama.
- `favicon.svg`: original lighthouse mark.
- Lora and DM Sans: served by Google Fonts with local serif/sans-serif fallbacks.

The itinerary downloader runs in the browser. It includes the selected plan and active language and does not collect or send personal information. The shared portfolio language control preserves the selected pace.

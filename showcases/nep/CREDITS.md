# Nếp Architects - sources and design notes

A fictional architectural practice and original frontend showcase by Lucas Nguyen. The three studies are observations on reference images, not completed projects attributed to Nếp Architects. SVG drawings are original abstract compositions and do not represent plans of the referenced projects.

## Experience

Text-only project list with a clear current-project marker, previous/next project navigation, image/drawing switch, notes and practice dialogs, image enlargement. Responsive single-column layout on small screens. Bitter and Source Sans 3 load from Google Fonts with local serif/sans-serif fallbacks. No application dependencies, backend or data collection.

Palette refinement: warm coral sidebar, sand background, dark brown text, inspired by TONIC.INC. Upright Bitter slab-serif headings and Source Sans 3 body type distinguish Nếp Architects from the other showcases. Navigation uses 13–16px text; main body copy uses 17px.
